# Academic Research Group Website

A responsive Jekyll theme for a research group website, prepared for GitHub Pages.

## Pages

- Home
- News
- Research
- Publications
- Team
- Gallery
- Openings

## Deploy

1. Edit `url` and `baseurl` in `_config.yml`.
2. Push the files to your GitHub repository.
3. In **Settings → Pages**, deploy from the branch containing the site.
4. Wait for the GitHub Pages build to finish.

Detailed editing notes are in [`README_CUSTOMIZE.md`](README_CUSTOMIZE.md).

The original Allan Lab content and images remain as demo material and should be replaced with your group's information.
